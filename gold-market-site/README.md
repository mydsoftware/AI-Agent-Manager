# سایت قیمت لحظه‌ای طلا و سکه

این پروژه یک داشبورد فارسی و واکنش‌گرا برای نمایش قیمت طلا و سکه است.

## منبع داده

منبع فعلی داده `tgju.org` و صفحه بازار داخلی است. سرور سایت داده را دریافت می‌کند و از طریق مسیر `/api/prices` به رابط کاربری می‌دهد تا مشکل CORS سمت مرورگر ایجاد نشود.

طبق راهنمای رسمی TGJU، وب‌سرویس رسمی نرخ‌های لحظه‌ای در قالب JSON و XML ارائه می‌شود و برای استفاده از آن باید سرویس مربوطه تهیه و توکن دریافت شود. بنابراین این نسخه برای نمونه‌سازی از صفحه عمومی TGJU استفاده می‌کند؛ برای نسخه تجاری بهتر است آداپتر دریافت داده به وب‌سرویس رسمی TGJU متصل شود.

## قیمت‌های نمایش داده‌شده

- طلای ۱۸ عیار / ۷۵۰
- طلای ۲۴ عیار
- سکه امامی
- سکه بهار آزادی
- نیم سکه
- ربع سکه
- سکه گرمی

رابط کاربری هر ۱۰ ثانیه داده جدید را درخواست می‌کند.

## اجرا

```bash
npm install
npm run dev
```

سپس برنامه را روی آدرس محلی Next.js باز کنید.

در Vercel، مسیر ریشه پروژه را روی `gold-market-site` قرار دهید و Build را اجرا کنید.
