# سایت ثبت شرکت — خروجی AI-Agent-Manager

این پوشه یک خروجی مستقل و قابل استقرار برای سایت خدمات ثبت شرکت است.

## ویژگی‌ها
- فارسی و RTL
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- صفحه فرود خدمات ثبت شرکت
- خدمات ثبت شرکت، تغییرات، ثبت برند و مجوز
- بخش مراحل ثبت
- بخش مزیت‌ها
- FAQ
- فرم درخواست مشاوره
- بدون وابستگی به فریم‌ورک؛ مناسب GitHub Pages / Vercel / هر وب‌سرور ساده

## وضعیت
فرم فعلاً Frontend-only است و برای استفاده واقعی باید به مقصدی مانند CRM، API، واتساپ یا فرم لید متصل شود.
